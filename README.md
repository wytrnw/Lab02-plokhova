ПР2. Ответы на контрольные вопросы

1.double хранит числа неточно. Если много раз складывать и умножать, ошибки копятся и в итоге может получиться не 100 рублей, а 99,99 или 100,01. А decimal считает точно, как на калькуляторе, поэтому его используют для денег.

2.В обычном режиме число перепрыгивает с конца на начало. У byte максимум 255, значит, если к 255 прибавить 1, получится 0, а не ошибка.

3.В C# var это просто сокращение, компилятор сам подставляет тип при сборке программы, но потом тип уже не меняется. В Python тип переменной может меняться в любой момент, сначала это число, потом вдруг строка.

4.Всегда строку (string). Даже если человек ввёл «123», программа получит текст «123», а не число. Чтобы получить число, надо отдельно преобразовать.

5.int.Parse при ошибке сразу ломается и выдаёт исключение. int.TryParse не ломается, он честно говорит что не получилось (возвращает false) и даёт шанс обработать ситуацию спокойно.

6.false значит не получилось превратить текст в число. А в переменную, которую передали через out, запишется ноль, это значение по умолчанию для int.

7.Когда данные приходят от пользователя или из внешнего файла часто бывает опечатка или неверный формат. Например, человек вместо возраста ввёл буквы. TryParse позволит просто написать «введите число», а не ловить ошибку через сложный блок try-catch.
